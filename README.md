# 🏠 PG & Hostel Booking System

A web-based PG and Hostel Booking System designed to make finding and booking accommodation easier for students and working professionals.

## 📌 Project Overview

The PG & Hostel Booking System is a web application that allows users to explore available PG accommodations, view property details, register, log in and manage their bookings.

The system also provides administrative pages to manage PG listings and bookings.

## 🚀 Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB
- Mongoose

## ✨ Main Features

- User Registration and Login
- PG and Hostel Listings
- View PG and Room Details
- Booking Management
- User Dashboard
- My Bookings
- Admin Dashboard
- Add and Manage PG Properties
- Booking Administration
- Reviews Management
- Payment Page

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/tanishkamedhekar03-pixel/PG-HOSTEL-BOOKING-SYSTEM.git
```

### 2. Open the Project

```bash
cd PG-HOSTEL-BOOKING-SYSTEM
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Configure Environment Variables

Create a `.env` file inside the backend folder.

Configure your MongoDB connection string and server port according to your backend configuration.

### 5. Start the Server

```bash
node server.js
```
